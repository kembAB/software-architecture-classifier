======================================================================
ArchitectureScope - Software Architecture Style Classifier
======================================================================

Classifies a software system into one of six architecture
styles from eight measurable structural features, using a
k-nearest-neighbours classifier with k = 3.

----------------------------------------------------------------------
DATASET
----------------------------------------------------------------------
36 labelled example systems, 6 per style.
Styles: Client-Server, Event-Driven, Layered, Microservices, Monolith, Pipe-and-Filter
Every system is measured on the same eight features:
  1. deployment_units
  2. independent_deployment
  3. own_database_per_unit
  4. async_communication_ratio
  5. coupling_score
  6. sequential_pipeline_flow
  7. client_request_driven
  8. team_autonomy

----------------------------------------------------------------------
EVALUATION - LEAVE-ONE-OUT CROSS-VALIDATION
----------------------------------------------------------------------
Each of the 36 systems was classified using the other 35 as
the reference set, and the prediction was checked against
the true style.

Overall accuracy: 36/36 = 100.0%

Per-style results:
  Client-Server   6/6 correct
  Event-Driven    6/6 correct
  Layered         6/6 correct
  Microservices   6/6 correct
  Monolith        6/6 correct
  Pipe-and-Filter 6/6 correct

Misclassifications: none. Every system was matched to
its true style by its three nearest neighbours.
